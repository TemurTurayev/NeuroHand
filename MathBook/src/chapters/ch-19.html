Векторы, матрицы и линейные системы

Как превратить таблицу биологических измерений в объект, с которым умеет работать алгоритм.

Один пациент — это не одно число. Возраст, давление, экспрессия генов, лабораторные показатели образуют вектор признаков. Если поставить векторы многих пациентов строками, получится матрица данных. Именно так таблица из клиники становится математикой.

Вектор — упорядоченный набор

Вектор x = (x₁,…,xₙ) хранит и значения, и их порядок. Сумма считается покомпонентно, умножение на число меняет масштаб. Длина ||x||₂ = √(Σxᵢ²), а скалярное произведение x·w = Σxᵢwᵢ измеряет совпадение направлений и строит взвешенную сумму.

Пример · Индекс риска

После стандартизации признаки пациента равны x=(0.5,−1,2), веса модели w=(0.4,0.2,0.3). Тогда score = x·w = 0.2−0.2+0.6 = 0.6. Каждый вес показывает вклад соответствующего признака.

Важно

Нельзя складывать «годы», «мм рт. ст.» и «ммоль/л» как есть. Перед моделированием признаки обычно центрируют и масштабируют; иначе большая единица измерения может доминировать без биологической причины.

Матрица — набор линейных преобразований

Матрица A размера m×n переводит вектор из n координат в m. Произведение Ax состоит из скалярных произведений строк A с x. Для AB внутренние размеры обязаны совпасть; порядок обычно нельзя менять: AB ≠ BA.

Am×nxn×1 = ym×1  ·  (AB)ij = ΣkAikBkj

Система Ax=b

Метод Гаусса заменяет строки эквивалентными и приводит расширенную матрицу к ступенчатому виду. Единственное решение означает независимые ограничения; свободная переменная — бесконечно много решений; строка 0=1 — несовместность.

Пример · Смесь двух растворов

x+y=10, 0.1x+0.3y=2. Вычтем 0.1 первой строки из второй: 0.2y=1, значит y=5 и x=5. Это и есть исключение Гаусса в бытовой форме.

Матрица X имеет 120 строк-пациентов и 8 столбцов-признаков. Каков размер Xw, если w содержит 8 весов?
Python mini-lab · NumPy
import numpy as np
X = np.array([[0.5, -1, 2], [1, 0, -0.5]])
w = np.array([0.4, 0.2, 0.3])
print(X @ w)
A = np.array([[1, 1], [.1, .3]])
b = np.array([10, 2])
print(np.linalg.solve(A, b))

Vectors, matrices, and linear systems

Turning a table of biological measurements into an object an algorithm can use.

A patient is not one number. Age, blood pressure, gene expression, and laboratory values form a feature vector. Stack many patient vectors as rows and you obtain a data matrix.

Vectors are ordered collections

A vector x=(x₁,…,xₙ) preserves both values and order. Addition is componentwise. Its Euclidean length is ||x||₂=√(Σxᵢ²); the dot product x·w=Σxᵢwᵢ is a weighted sum and a measure of directional agreement.

Example · Risk score

For standardized features x=(0.5,−1,2) and model weights w=(0.4,0.2,0.3), the score is x·w=0.6. Each weight controls the contribution of one feature.

Important

Raw years, mmHg, and mmol/L should not be combined blindly. Features are commonly centered and scaled so measurement units do not dominate the biology.

Matrices are linear transformations

An m×n matrix maps an n-vector to an m-vector. Each entry of Ax is the dot product of one row with x. Inner dimensions must match, and order matters: usually AB≠BA.

Am×nxn×1 = ym×1  ·  (AB)ij = ΣkAikBkj

The system Ax=b

Gaussian elimination uses solution-preserving row operations. A pivot for every unknown gives a unique solution; a free variable gives infinitely many; a row equivalent to 0=1 means no solution.

Example · Mixing two solutions

x+y=10 and 0.1x+0.3y=2. Subtract 0.1 times the first equation from the second: 0.2y=1, so x=y=5.
