Собственные векторы и PCA

Как найти устойчивые направления в данных с тысячами коррелирующих признаков.

В транскриптомике генов много, но изменения часто движутся несколькими согласованными программами. PCA ищет направления, вдоль которых данные меняются сильнее всего, и показывает сложное облако в нескольких координатах.

Особые направления преобразования

Собственный вектор v матрицы A не поворачивается после преобразования: Av=λv. Число λ говорит, насколько направление растянулось и сменило ли знак. Нулевой вектор не считается собственным.

Пример

Для A=diag(3,0.5) оси координат — собственные направления. Вдоль первой всё растягивается втрое, вдоль второй сжимается вдвое.

От ковариации к главным компонентам

Сначала центрируем столбцы X. Ковариационная матрица C=XᵀX/(n−1) описывает совместные изменения признаков. Её собственный вектор с наибольшим λ — PC1; следующий ортогональный — PC2. Доля λᵢ/Σλ показывает объяснённую дисперсию.

Интерпретация без самообмана

PCA не знает диагнозов и не доказывает причинность. Компонента — линейная комбинация признаков; знак вектора условен, а сильный batch effect может стать PC1 вместо биологии.

center X → C = XᵀX/(n−1) → Cv = λv → scores = Xv
Что означает, что PC1 объясняет 62% дисперсии?
Python mini-lab · PCA вручную
import numpy as np
X = np.array([[2., 1.], [3., 2.], [4., 4.], [5., 5.]])
Xc = X - X.mean(axis=0)
C = np.cov(Xc, rowvar=False)
values, vectors = np.linalg.eigh(C)
order = values.argsort()[::-1]
print(values[order] / values.sum())
print(Xc @ vectors[:, order[:1]])

Eigenvectors and PCA

Finding stable directions in data with thousands of correlated features.

Transcriptomic datasets contain many genes, yet their changes often follow a few coordinated programs. PCA finds directions of greatest variation and projects a complex cloud into a few coordinates.

Special directions of a transformation

An eigenvector v does not change direction under A: Av=λv. The eigenvalue λ gives the scale and possible sign reversal. The zero vector is excluded.

Example

For A=diag(3,0.5), the coordinate axes are eigenvectors: one direction stretches threefold and the other contracts by half.

From covariance to principal components

Center the columns of X. The covariance matrix C=XᵀX/(n−1) describes joint variation. Its eigenvector with the largest λ is PC1; the next orthogonal direction is PC2. The ratio λᵢ/Σλ is explained variance.

Interpret carefully

PCA does not know labels and cannot establish causality. A component is a linear combination; its sign is arbitrary, and a batch effect may become PC1 instead of biology.

center X → C = XᵀX/(n−1) → Cv = λv → scores = Xv
What does it mean when PC1 explains 62% of variance?
Python mini-lab · PCA by hand
import numpy as np
X = np.array([[2., 1.], [3., 2.], [4., 4.], [5., 5.]])
Xc = X - X.mean(axis=0)
C = np.cov(Xc, rowvar=False)
values, vectors = np.linalg.eigh(C)
order = values.argsort()[::-1]
print(values[order] / values.sum())
print(Xc @ vectors[:, order[:1]])
