Глава 21 · QLS Extension

Производные, градиенты и оптимизация

Математика скорости изменения — от фармакокинетики до обучения модели.

Концентрация лекарства меняется во времени, а ошибка модели — при изменении параметров. Производная отвечает на один вопрос: что произойдёт с выходом при очень малом изменении входа?

Локальный наклон

f′(x)=limh→0[f(x+h)−f(x)]/h. Если f′>0, функция локально растёт; если f′<0 — падает. Единицы производной — «единицы выхода на единицу входа».

Пример · Элиминация препарата

C(t)=100e−0.2t, поэтому C′(t)=−20e−0.2t=−0.2C(t). Скорость выведения пропорциональна текущей концентрации.

Несколько переменных

Частная производная меняет одну координату, фиксируя остальные. Градиент ∇L=(∂L/∂w₁,…) указывает направление самого быстрого роста. Поэтому градиентный спуск идёт в противоположную сторону:

wnew = wold − η∇L(w)

Слишком большой learning rate η перепрыгивает минимум; слишком маленький учится медленно. В точке минимума градиент равен нулю лишь как необходимый признак: это также может быть максимум или седло.

Пример · Один шаг обучения

Если L(w)=(w−3)², то L′=2(w−3). При w=0, η=0.1: новый вес 0−0.1(−6)=0.6, то есть ближе к минимуму w=3.

Градиент loss в текущей точке равен (4, −2). В каком направлении делает шаг gradient descent?
Python mini-lab · численная производная
def f(w): return (w - 3)**2
def derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2*h)
w, eta = 0.0, 0.1
for _ in range(8):
    w -= eta * derivative(f, w)
    print(round(w, 4), round(f(w), 4))

Chapter 21 · QLS Extension

Derivatives, gradients, and optimization

The mathematics of change, from pharmacokinetics to model training.

Drug concentration changes with time, and model loss changes with its parameters. A derivative asks what happens to the output after a very small input change.

Local slope

f′(x)=limh→0[f(x+h)−f(x)]/h. Positive means local increase and negative means decrease. Its units are “output units per input unit.”

Example · Drug elimination

For C(t)=100e−0.2t, C′(t)=−20e−0.2t=−0.2C(t). Elimination rate is proportional to current concentration.

Several variables

A partial derivative changes one coordinate while holding the others fixed. The gradient ∇L=(∂L/∂w₁,…) points toward steepest increase, so gradient descent moves against it:

wnew = wold − η∇L(w)

A large η can overshoot; a small one learns slowly. Zero gradient is necessary at a smooth minimum but may also indicate a maximum or saddle.

Example · One training step

If L(w)=(w−3)², then L′=2(w−3). At w=0, η=0.1, the new weight is 0.6, closer to the minimum at 3.

The loss gradient is (4, −2). In which direction does gradient descent move?
Python mini-lab · numerical derivative
def f(w): return (w - 3)**2
def derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2*h)
w, eta = 0.0, 0.1
for _ in range(8):
    w -= eta * derivative(f, w)
    print(round(w, 4), round(f(w), 4))
