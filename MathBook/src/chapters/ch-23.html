Случайные величины и распределения

Как описывать не отдельный исход, а весь механизм неопределённости.

Вероятность из главы 13 отвечала на события. Теперь случайная величина присваивает каждому исходу число — количество мутаций, время выживания или уровень экспрессии — и позволяет изучать весь спектр возможных значений.

Распределение, ожидание, дисперсия

Дискретная величина имеет вероятности P(X=x); непрерывная — плотность, где вероятность равна площади интервала. Для непрерывной X вероятность одной точной точки равна нулю.

E[X]=ΣxP(X=x)  ·  Var(X)=E[(X−μ)²]  ·  SD=√Var

Ожидание — долгосрочный центр, не обязательно возможный исход. Дисперсия измеряет квадрат отклонения и имеет квадратные единицы; SD возвращает исходные единицы.

Четыре рабочих распределения

РаспределениеКогда применятьПараметры
Bernoulliодин успех/неуспехp
Binomialчисло успехов в n независимых попыткахn,p
Poissonчисло редких событий на интервалλ

Пример · Число ответивших

Если вероятность ответа на терапию 0.3 и пациенты независимы, то X~Binomial(10,0.3). E[X]=np=3, Var=np(1−p)=2.1. Это не обещает ровно три ответа в каждой группе.

Условия важнее формулы

Binomial требует фиксированное n, одинаковое p, два исхода и независимость. Если пациенты влияют друг на друга или p меняется, привычная формула может быть неверна.

Какое распределение естественно для числа новых мутаций на фиксированном участке при редких независимых событиях?
Python mini-lab · симуляция
import numpy as np
rng = np.random.default_rng(7)
x = rng.binomial(n=10, p=.3, size=10000)
print(x.mean(), x.var())
y = rng.poisson(lam=2.5, size=10000)
print(y.mean(), y.var())

Random variables and distributions

Describing an entire mechanism of uncertainty rather than one outcome.

A random variable assigns a number to every outcome: mutation count, survival time, or expression level. Its distribution describes the full range of possible values.

Distribution, expectation, variance

A discrete variable has probabilities P(X=x). A continuous variable has a density, and interval probability is area; any exact point has probability zero.

E[X]=ΣxP(X=x)  ·  Var(X)=E[(X−μ)²]  ·  SD=√Var

Expectation is a long-run center, not necessarily a possible outcome. Variance has squared units; SD returns to the original units.

Four working distributions

DistributionUseParameters
Bernoullione success/failurep
Binomialsuccesses in n independent trialsn,p
Poissonrare-event count per intervalλ
Normalcontinuous symmetric variationμ,σ
Example · Number of responders

With independent patients and response probability 0.3, X~Binomial(10,0.3). Then E[X]=3 and Var=2.1; this does not guarantee exactly three responses.

Conditions before formulas

Binomial requires fixed n, equal p, two outcomes, and independence. Dependence or varying probabilities break the simple model.
