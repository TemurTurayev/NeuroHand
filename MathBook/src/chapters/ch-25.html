Линейные модели и математика ML

Как связать матрицы, производные и статистику в первый настоящий предиктивный алгоритм.

Линейная регрессия выглядит скромно, но в ней уже есть весь цикл машинного обучения: признаки, параметры, предсказание, loss, оптимизация, проверка на новых данных и интерпретация с оговорками.

Модель и остатки

ŷ=Xβ. Вектор β содержит коэффициенты, а остаток e=y−ŷ — то, что модель не объяснила. Метод наименьших квадратов минимизирует MSE=(1/n)Σ(yᵢ−ŷᵢ)².

Пример · Интерпретация

В модели давления ŷ=95+0.6·age−4·treatment коэффициент 0.6 означает среднюю разницу 0.6 mmHg на год при фиксированном treatment. Это условная ассоциация, не автоматически причинный эффект.

Обобщение и regularization

Train error оценивает подгонку знакомых данных; test error — перенос на новые. Слишком гибкая модель запоминает шум. Ridge добавляет λΣβⱼ² и мягко уменьшает коэффициенты; Lasso добавляет λΣ|βⱼ| и может занулять некоторые.

Утечка данных

Разделяй train/test до масштабирования и выбора признаков. Если test участвовал в подготовке модели, это уже не честная проверка. Для малых данных используй cross-validation, но сохраняй финальный независимый test.

От регрессии к классификации

Логистическая регрессия превращает линейный score в вероятность: p=1/(1+e−z), где z=Xβ. Порог переводит вероятность в класс, но выбор порога меняет чувствительность и специфичность.

данные X → score Xβ → prediction → loss → gradient → обновлённые β
Модель имеет почти нулевую train error, но большую test error. Наиболее вероятная проблема?
Python mini-lab · линейная регрессия без библиотек ML
import numpy as np
age = np.array([20, 30, 40, 50, 60.])
y = np.array([108, 112, 121, 126, 132.])
X = np.c_[np.ones(len(age)), age]
beta = np.linalg.solve(X.T @ X, X.T @ y)
prediction = X @ beta
print(beta)
print(((y - prediction)**2).mean())
Финальный босс · Честный pipeline

У тебя 200 пациентов и 5 000 генов. Сформулируй порядок действий: split, preprocessing, feature selection, обучение, настройка и оценка. Где должна происходить каждая операция, чтобы test не утёк в модель?

Один корректный скелет

Сначала отделить финальный test. Всё обучение preprocessing, отбор генов и подбор гиперпараметров выполнять только внутри training data, лучше внутри folds cross-validation. После выбора pipeline один раз оценить его на нетронутом test и сообщить метрику вместе с неопределённостью и ограничениями.

QLS-мост построен
  • видишь линейную модель как Xβ;
  • различаешь fit и generalization;
  • связываешь loss, gradient и regularization;
  • защищаешь оценку от data leakage.
Chapter 25 · QLS Extension

Linear models and the mathematics of ML

Connecting matrices, derivatives, and statistics into a real predictive algorithm.

Linear regression already contains the full machine-learning cycle: features, parameters, predictions, loss, optimization, evaluation on new data, and careful interpretation.

Model and residuals

ŷ=Xβ. The vector β contains coefficients; e=y−ŷ contains residuals. Least squares minimizes MSE=(1/n)Σ(yᵢ−ŷᵢ)².

Example · Interpretation

In ŷ=95+0.6·age−4·treatment, 0.6 is the average mmHg difference per year holding treatment fixed. It is a conditional association, not automatically a causal effect.

Generalization and regularization

Training error measures fit to familiar data; test error measures transfer to new data. Ridge adds λΣβⱼ² and shrinks coefficients; Lasso adds λΣ|βⱼ| and may set some to zero.

Data leakage

Split train and test before scaling or feature selection. If test data shaped the model, it is no longer an honest evaluation. Cross-validation helps with small datasets, while a final test remains untouched.

From regression to classification

Logistic regression maps a linear score to probability: p=1/(1+e−z), where z=Xβ. A threshold creates classes, but changing it trades sensitivity against specificity.

data X → score Xβ → prediction → loss → gradient → updated β

Final boss · An honest pipeline

You have 200 patients and 5,000 genes. Order split, preprocessing, feature selection, training, tuning, and evaluation so test data cannot leak into the model.

One valid skeleton

Hold out final test data first. Learn preprocessing, gene selection, and hyperparameters using training data only, preferably inside cross-validation folds. Evaluate the chosen pipeline once on untouched test data and report the metric with uncertainty and limitations.

The QLS bridge is complete
  • see a linear model as Xβ;
  • separate fit from generalization;
  • connect loss, gradients, and regularization;
  • protect evaluation from data leakage.
